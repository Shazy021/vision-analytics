## Методология

- Работа строго снаружи: HTTP API и Prometheus, код платформы не меняется.
- Окна измерения зафиксированы по времени (прогрев 25.0с + окно 90.0с, масштаб streams, 10 fps на стрим); квантили и приросты — `increase` ровно за окно, без хвоста прошлой ступени.

- Скрейп Prometheus стенда: 15.0с — границы окна имеют точность ±одного скрейпа.
